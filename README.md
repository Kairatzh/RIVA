## RIVA

Run Intelligent Virtual Automations — open source DSL for LLM workflows

Версия DSL (концепция): 0.1.0  
Статус проекта: раннее проектирование языка и документации (без реализации рантайма)

### О проекте

RIVA — это декларативный язык (DSL) для описания:

- генерации контента (текст, код, структурированные данные);
- трансформации и анализа данных;
- мультиагентных LLM‑сценариев;
- работы с внешними источниками (API, файлы, базы данных);
- инфраструктурных аспектов (логирование, оценка стоимости, кеширование).

Цель — позволить пользователям, в том числе без опыта программирования, описывать сложные воркфлоу и мультиагентные системы в понятном текстовом формате.

### Структура репозитория

- `README.md` — общий обзор проекта и статуса;
- `docs/OVERVIEW.md` — концептуальное описание языка и его целей;
- `docs/LANGUAGE_REFERENCE.md` — справочник по синтаксису и ключевым конструкциям DSL;
- `docs/VERSIONING.md` — политика версионирования и подход к изменениям;
- `docs/LEARNING.md` — обучающий гид с пошаговым разбором и примерами;
- `examples/` — набор рабочих примеров сценариев на RIVA DSL.

### Примеры

Базовые примеры находятся в каталоге `examples/`:

- `article_basic.riva` — генерация статьи по теме и краткое резюме;
- `article_multi_agent.riva` — сценарий “писатель + критик”;
- `news_summary.riva` — загрузка новостей по API и создание сводки.

Каждый пример снабжен комментариями и дополнительно разобран в `docs/LEARNING.md`.

### Версионирование

Подход к версионированию DSL и будущего рантайма описан в `docs/VERSIONING.md`.  
На текущем этапе любые изменения могут вносить корректировки в спецификацию, но фиксируются через обновление документации.
